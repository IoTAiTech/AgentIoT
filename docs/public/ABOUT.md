## Product

AgentIoT Dashboard is an AI-powered, fault-tolerant IoT monitoring
portal. It is built for heterogeneous, multi-vendor device environments
in residential, commercial, and light-industrial settings.

Operators today jump between vendor-specific dashboards and isolated
logins. That fragments visibility, raises cost, and locks sites into
one manufacturer. AgentIoT brings those surfaces together.

### What it does

- Unified monitoring of heterogeneous IoT devices from different vendors
- AI-agent anomaly detection and automated diagnosis
- Agent-proposed corrective actions for stabilization and self-healing
- Secure central web access with asset and configuration management
- Support for legacy and end-of-support hardware (circular economy)
- Scalable architecture for fleet and network management

Recovery proposals stay behind human approval in this software cut.
The product does not execute physical mutations without an operator.
